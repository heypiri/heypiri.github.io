Privacy Policy

Last updated: 22 November 2026

Piri Studio is a private desktop tool used only by the owner of the Piri TikTok account. This policy explains what data it handles.

Data we receive from TikTok

  • Basic profile information (display name and avatar, scope user.info.basic): used only to show which account is connected before an upload.
  • Access token: issued by TikTok when the account owner signs in. It is used only to upload drafts (scope video.upload).

How it is stored

Tokens and profile information are stored only on the account owner's own computer. They are not sent to any server of ours, and we do not run one.

Sharing

We do not sell, share or transfer any data to third parties. We do not collect data about viewers or any other TikTok users.

Deleting data

The account owner can revoke Piri Studio's access at any time in the TikTok app under Settings → Security → Apps and services. Deleting the local token file removes all stored data.
